Your phone is a development machine.

qos puts a Linux terminal, VS Code, compilers, a desktop and the eTamil toolchain on your Android phone or tablet. Write, build and run real software anywhere, with no laptop and no account.

Editor

VS Code, inside the app

A full VS Code runs on the device and opens from the side drawer: the file tree, extensions from Open VSX, and a terminal underneath. No cloud and no sign-in; your code never leaves the phone unless you push it.

Best on a tablet with a keyboard. On a phone, the terminal and a text editor are often quicker.

Desktop New in 0.2

A Linux desktop when you need one

Tap Desktop in the drawer and qos opens XFCE on qos Desktop, its companion display. Run graphical tools: Krita and Inkscape for drawing and animation, Kdenlive for video, Godot for games, Wireshark for networks.

qos Desktop is a second app from the same source, signed with the same key, and runs as part of qos. The first start downloads about 100 MB.

Who it's for

For anyone with a phone and something to build

Most people who want to learn programming already own an Android phone. Far fewer own a laptop. qos is for them, and for anyone who wants their tools within reach.

Students

Learn Python, C, Java or Rust on the device you already carry, without waiting for a computer lab.

Tamil speakers learning to code

Write programs in Tamil with eTamil, and move on to other languages from the same terminal.

Teachers and colleges

Run programming classes on phones and tablets. Every student gets the same tools, set up the same way.

Working developers

Fix a bug, review a branch, push a commit or reach a server over SSH, away from your desk.

eTamil developers

Build and test eTamil programs, modules and servers on Android, with the real compiler.

Makers and tinkerers

Automate your phone, run small servers, talk to boards over Wi-Fi and explore Linux, safely, inside one app.

Trust

Open, private and verifiable

Open source

Every line is public under the GNU GPL v3, built on Termux and Termux:X11.

No account

No sign-in, no ads, no analytics, no telemetry. This website sets no cookies.

Signed releases

Every APK is signed with the qos key, and the F-Droid repository with its own; both fingerprints are published.

Built in the open

Releases are built by public GitHub workflows from tagged source, with SHA-256 checksums.

Get started

Three steps

Add the qos repository

In F-Droid, add the qos repository and check its fingerprint. Or download the APK from GitHub.

Install and open qos

On first launch qos sets up its tools. Use Wi-Fi: it downloads about 500 MB.

Start building

Type in the terminal, or swipe in from the left for VS Code and Desktop.
