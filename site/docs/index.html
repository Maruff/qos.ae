Using qos

From first launch to the desktop, and what to do when something goes wrong.

First launch

The first time qos opens, it installs its base system and then runs qos-setup, which installs git, clang, make, Python, Rust, Java 17, code-server and eTamil. It downloads about 500 MB, so use Wi-Fi and keep the screen on. You will see Done in the terminal when it finishes.

If setup is interrupted, it carries on at the next start. You can also run it again at any time:

qos-setup

The terminal

Install anything from the package collection with pkg:

pkg search postgres
pkg install postgresql

Swipe in from the left edge for the drawer: sessions, the keyboard toggle, VS Code and Desktop. Long-press the keyboard button to show or hide the extra keys row.

Your files

Your projects live in qos's home folder. To reach the phone's shared storage (Downloads, Pictures, camera footage), run once:

termux-setup-storage

It asks for permission and creates ~/storage with links to those folders.

VS Code

Tap VS Code in the drawer. qos starts code-server in the background if it is not already running, and signs you in with the password from ~/.config/code-server/config.yaml.

The password stays on deliberately: every app on the phone can reach 127.0.0.1:8080, and code-server can run commands. To start it yourself: code-server.

qos Desktop

Install qos Desktop from the qos F-Droid repository, then tap Desktop in the drawer. The first time, qos installs XFCE (about 100 MB) and the qos-x11 package, then opens the desktop. From a terminal: qos-desktop.

Stop it by logging out of XFCE, with Exit in the qos Desktop notification, or with Ctrl+C in the session that started it. Graphical programs started from a terminal need DISPLAY=:1.

If the screen stays black or colours look swapped, start it by hand with an option:

termux-x11 :1 -legacy-drawing -xstartup "xfce4-session"
termux-x11 :1 -force-bgra -xstartup "xfce4-session"

eTamil

Run an eTamil program with the virtual machine, and check one without running it:

etamil --vm program.qmz
etamil --check program.qmz

The standard library is in $ETAMIL_PATH, so இறக்கு "nUlakam/…" works from any folder. Learn the language at etamil.in.

Keeping work running

Android 12 and newer may stop long-running work in the background, such as builds, VS Code or the desktop. On Android 14 and later, turn on Developer options and enable Disable child process restrictions. Setting qos's battery use to Unrestricted also helps.

Updates

With the F-Droid repository, qos and qos Desktop update like any other app. Packages inside qos update with:

pkg upgrade

Troubleshooting

Setup stopped with an error

Check the internet connection and run qos-setup again. Each step is safe to repeat.

"qos Desktop is not installed"

Install qos Desktop from the qos F-Droid repository or the qos-desktop GitHub release, then tap Desktop again.

"Signature verification … failed"

qos Desktop and the qos-x11 package come from different sources. Install both from qos releases, not from Termux.

VS Code does not open

Run code-server in the terminal to see the error. If it is not installed, run qos-setup.

Questions

Is qos free?

Yes. qos is free software under the GNU GPL v3, with no ads, no in-app purchases and no account.

Does qos need root?

No. Everything runs inside the app's own storage, with normal app permissions.

How is qos different from Termux?

qos is built on Termux and keeps its package collection. It adds a one-time setup of a complete toolset, VS Code inside the app, qos Desktop and eTamil, so a new phone becomes a development machine without configuration.

Can I keep Termux installed?

No. qos uses Termux's package name so that every Termux package works, and Android allows one app with that name.

Why is qos not on Google Play?

Play requires apps to target recent Android versions, which do not let an app run programs it downloads. A development machine has to do exactly that.

qos turns an Android phone or tablet into a development machine. Free software under the GNU GPL v3.
