English qos பெறுக

வசதிகள்

ஒரு நிரலாக்கக் கணினிக்குத் தேவையான அனைத்தும்

லினக்ஸ் முனையம், உண்மையான தொகுப்பிகள், VS Code, மேசைத்தளம், இ-தமிழ் — உங்கள் கைபேசியிலோ டேப்லெட்டிலோ ஒரே செயலியில்.

விளக்கப்படம்

முனையம்

உண்மையான லினக்ஸ் முனையம்

qos, Termux-ஐ அடிப்படையாகக் கொண்டது; அதனால் முழு Termux தொகுப்புத் திரட்டும் இயங்கும்: ஆயிரக்கணக்கான தொகுப்புகள், pkg install கொண்டு நிறுவலாம். கூடுதல் விசை வரிசை தொடுதிரையிலும் Esc, Ctrl, Tab, அம்புக்குறி விசைகளைத் தருகிறது.

git, clang, make, Python, Rust, Java 17 ஆகியவை VS Code, இ-தமிழ் உடன் qos முதல் முறை திறக்கும்போதே அமைகின்றன.

விளக்கப்படம்

திருத்தி

செயலிக்குள்ளேயே VS Code

code-server கைபேசியிலேயே இயங்கி, பக்கப் பட்டியிலிருந்து திறக்கிறது. code-server-இன் சொந்தக் கடவுச்சொல்லைக் கொண்டு qos உங்களை உள்நுழைக்கிறது; கைபேசியில் உள்ள எந்தச் செயலியும் அது கேட்கும் port-ஐ அணுக முடியும் என்பதால் அந்தக் கடவுச்சொல்லை இயக்கத்திலேயே வைத்திருக்கிறது.

நீட்சிகள் திறந்த நீட்சிப் பதிவகமான Open VSX-இலிருந்து வருகின்றன.

விளக்கப்படம்

மேசைத்தளம் 0.2-இல் புதியது

qos Desktop

Termux:X11-இலிருந்து கட்டப்பட்ட துணைத் திரையான qos Desktop-இல் XFCE மேசைத்தளம். இது qos-இன் ஒரு பகுதியாக இயங்குவதால், ஆண்ட்ராய்டு இரண்டையும் ஒரே செயலியாகக் கருதுகிறது. சாளரங்கள் உள்ள எதற்கும் பயன்படுத்துங்கள்: Krita, Inkscape, GIMP, Kdenlive, Shotcut, Audacity, Godot, Wireshark, Firefox.

கைபேசிகளில் கணினி வரைகலை இயக்கிகள் இல்லை; அதனால் கனமான 3D மெதுவாக இருக்கும். சுட்டியோ தொடுதிண்டுடன் கூடிய விசைப்பலகையோ உதவும்.

விளக்கப்படம்

இ-தமிழ்

தமிழில் நிரலாக்கம்

இ-தமிழ் தொகுப்பியும் அதன் நிலையான நூலகமான நூலகமும் முதல் முறை திறக்கும்போதே நிறுவப்படுகின்றன. இ-தமிழ் நிரல்கள் கோப்புகளைப் படிக்கும், SQLite பயன்படுத்தும், இணைய API-களை அழைக்கும், சேவையகங்களை இயக்கும்.

qos தற்போது இ-தமிழின் பொது லினக்ஸ் பதிப்பை வழங்குகிறது; அதில் இணைய முகவரிகளைப் பெயரால் தேடுவது ஆண்ட்ராய்டில் இயங்காமல் போகலாம். ஆண்ட்ராய்டுக்கென்றே கட்டிய பதிப்பு திட்டப் பாதையில் அடுத்தது.

நிரலுக்கு அப்பால்

செயலிகள், விளையாட்டுகள், கார்ட்டூன்கள், திரைப்படங்கள், IoT, பாதுகாப்பு, AI

ஒவ்வொரு வகைப் பணியும் இன்று qos-இல் எப்படி இருக்கிறது, திட்டப் பாதை எதைச் சேர்க்கிறது, அதன் வரம்புகள் என்ன — தொகுப்புத் திரட்டுகளில் உண்மையில் உள்ளவற்றின் அடிப்படையில்.

கைபேசிச் செயலிகள்

இன்று

முனையத்திலிருந்தே ஆண்ட்ராய்டு செயலிகளைக் கட்டலாம்: Java 21, Kotlin, Gradle, aapt2, d8, apksigner, adb அனைத்தும் தொகுப்புத் திரட்டில் உள்ளன. வலைச் செயலிகள் முழுமையாக இயங்கும்.

வருகிறது

ஒரே படியில் அமையும் ஆண்ட்ராய்டு கருவித்தொகுப்பு; ஒரே கட்டளையில் அதே கைபேசியில் கட்டி நிறுவும் தொடக்கத் திட்டம்.

வரம்புகள்

மடிக்கணினியை விடக் கட்டுமானம் மெதுவாக நடக்கும். Flutter இன்னும் ஆண்ட்ராய்டு சாதனங்களில் இயங்காது.

விளையாட்டுகள்

இன்று

HTML5, JavaScript-இல் வலை விளையாட்டுகள்; எந்த மொழியிலும் உரை விளையாட்டுகள். qos Desktop உடன்: Godot 4, LÖVE, pygame, raylib.

வருகிறது

தொடக்கத் திட்டங்களுடன் ஒரே படியில் அமையும் விளையாட்டுக் கருவித்தொகுப்பு.

வரம்புகள்

2D-யும் எளிய 3D-யும் மட்டும். கனமான 3D விளையாட்டுகளுக்குத் தேவையான வரைகலை இயக்கிகள் கைபேசிகளில் இல்லை.

கார்ட்டூன்களும் அசைவூட்டமும்

இன்று

manim கொண்டு விளக்க அசைவூட்டங்கள், ImageMagick கொண்டு படப் பணிகள். qos Desktop உடன்: Krita-வில் சட்டகம் சட்டகமாக அசைவூட்டம், Inkscape, GIMP-இல் வரைதல்.

வருகிறது

இந்தக் கருவிகள் ஒரே படியில் அமையும் படைப்புக் கருவித்தொகுப்பு.

வரம்புகள்

Blender இல்லை, எனவே 3D அசைவூட்டம் இல்லை. நீண்ட வரைவாக்கங்கள் மெதுவாக நடக்கும், கைபேசி சூடாகும்.

திரைப்படங்கள்

இன்று

ffmpeg கொண்டு தொகுக்கலாம்: வெட்டுதல், இணைத்தல், இசை, தமிழ் வசனவரிகள் சேர்த்தல், YouTube அல்லது WhatsApp-க்கு ஏற்றுமதி. qos Desktop உடன்: Kdenlive, Shotcut, Audacity.

வருகிறது

தொகுப்பு, ஒலி, வசனவரிக் கருவிகள் ஒரே படியில் அமையும் திரைப்படக் கருவித்தொகுப்பு.

வரம்புகள்

படம்பிடிப்பது கைபேசியின் சொந்தக் கேமரா செயலியில்; qos காட்சிகளைத் தொகுக்கும். 4K காணொளி வரைவாக்கம் மெதுவாக இருக்கும்.

IoT

இன்று

Mosquitto கொண்டு MQTT, Python, Node.js சேவைகள், Wi-Fi வழியே ESP32 அல்லது Arduino பலகைகளுடன் தொடர்பு.

வருகிறது

IoT கருவித்தொகுப்பு: MQTT தரகர், கட்டுப்பாட்டுப் பலகைகள், ESP32 பலகைகளுக்கு வான்வழிப் புதுப்பிப்புகள்.

வரம்புகள்

ரூட் இல்லாமல் USB வழியே பலகைகளில் நிரலேற்றுவது ஆண்ட்ராய்டில் கடினம். அதையும், கைபேசியிலிருந்தே Arduino-வில் இ-தமிழையும் ஆராய்ந்து வருகிறோம்.

இணையப் பாதுகாப்பு

இன்று

nmap கொண்டு உங்கள் சொந்த வலையமைப்பை வருடலாம்; GnuPG, age கொண்டு மறையாக்கம்; WireGuard, Tor; ClamAV, YARA கொண்டு கோப்புச் சோதனை; radare2, gdb, apktool, jadx கொண்டு நிரல்களையும் ஆண்ட்ராய்டு செயலிகளையும் பிரித்தாய்தல்.

வருகிறது

கற்பதற்கும் காப்பதற்குமான பாதுகாப்புக் கருவித்தொகுப்பு, பயிற்சிகளுடன்; qos Desktop-இல் Wireshark.

வரம்புகள்

வலையமைப்புப் போக்குவரத்தைப் பிடிப்பதற்கும் Wi-Fi கண்காணிப்புக்கும் ரூட் தேவை. தாக்குதல் கருவித்தொகுப்புகள் சேர்க்கப்படவில்லை.

செயற்கை நுண்ணறிவு (AI)

இன்று

llama.cpp அல்லது Ollama கொண்டு திறந்த மொழி மாதிரிகளைக் கைபேசியிலேயே இயக்கலாம்; PyTorch, ONNX Runtime, NumPy, SciPy கொண்டு இயந்திரக் கற்றல். கணக்கும் இல்லை, கட்டண AI சேவையும் இல்லை.

வருகிறது

உள்ளூர் AI கருவித்தொகுப்பு: தேர்ந்த மாதிரி பதிவிறக்கப்பட்டு ஆயத்தமாக; சாதனத்திலேயே இயங்கும் VS Code நிரல் உதவியாளர்.

வரம்புகள்

சிறிய மாதிரிகள் மட்டும்: சுமார் 100 கோடி முதல் 400 கோடி அளவுருக்கள், 4 முதல் 8 GB RAM தேவை. மேகச் சேவைகளை விடப் பதில்கள் மெதுவாக வரும்.

யாருக்காக

கற்பவர்களுக்கும் உருவாக்குநர்களுக்குமாகக் கட்டப்பட்டது

மாணவர்கள்

கணினி ஆய்வகத்துக்குக் காத்திருக்காமல், கையில் உள்ள கைபேசியிலேயே Python, C, Java, Rust கற்கலாம்.

நிரலாக்கம் கற்கும் தமிழர்கள்

இ-தமிழில் தமிழிலேயே நிரல் எழுதுங்கள்; அதே முனையத்திலிருந்து பிற மொழிகளுக்கும் செல்லுங்கள்.

ஆசிரியர்களும் கல்லூரிகளும்

கைபேசிகளிலும் டேப்லெட்டுகளிலும் நிரலாக்க வகுப்புகளை நடத்துங்கள். ஒவ்வொரு மாணவருக்கும் ஒரே கருவிகள், ஒரே அமைப்பு.

பணிபுரியும் நிரலாளர்கள்

மேசையை விட்டு விலகியிருக்கும்போதும் பிழை திருத்தலாம், கிளையைச் சரிபார்க்கலாம், commit அனுப்பலாம், SSH வழியே சேவையகத்தை அணுகலாம்.

இ-தமிழ் நிரலாளர்கள்

உண்மையான தொகுப்பியைக் கொண்டு இ-தமிழ் நிரல்கள், கூறுகள், சேவையகங்களை ஆண்ட்ராய்டிலேயே கட்டிச் சோதிக்கலாம்.

உருவாக்குநர்களும் ஆர்வலர்களும்

கைபேசிப் பணிகளைத் தானியக்கமாக்குங்கள், சிறு சேவையகங்களை இயக்குங்கள், Wi-Fi வழியே பலகைகளுடன் பேசுங்கள், லினக்ஸை ஒரே செயலிக்குள் பாதுகாப்பாக ஆராயுங்கள்.

qos ஆண்ட்ராய்டு கைபேசியையோ டேப்லெட்டையோ நிரலாக்கக் கணினியாக மாற்றுகிறது. GNU GPL v3 உரிமத்தின் கீழ் கட்டற்ற மென்பொருள்.
