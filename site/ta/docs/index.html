ஆவணங்கள்

qos-ஐப் பயன்படுத்துதல்

முதல் முறை திறப்பதிலிருந்து மேசைத்தளம் வரை; ஏதாவது தவறினால் என்ன செய்வது.

முதல் முறைமுனையம்உங்கள் கோப்புகள்VS Codeqos Desktopஇ-தமிழ்பணி நிற்காமல் இருக்கபுதுப்பிப்புகள்சிக்கல் தீர்வுகேள்விகள்

முதல் முறை திறக்கும்போது

qos முதல் முறை திறக்கும்போது தன் அடிப்படை அமைப்பை நிறுவி, பின் qos-setup-ஐ இயக்குகிறது; அது git, clang, make, Python, Rust, Java 17, code-server, இ-தமிழ் ஆகியவற்றை நிறுவுகிறது. சுமார் 500 MB பதிவிறக்கும்; எனவே Wi-Fi பயன்படுத்தித் திரையை அணையாமல் வைத்திருங்கள். முடிந்ததும் முனையத்தில் Done தெரியும்.

அமைப்பு இடையில் நின்றால், அடுத்த முறை தொடரும். எப்போது வேண்டுமானாலும் மீண்டும் இயக்கலாம்:

qos-setup

முனையம்

தொகுப்புத் திரட்டிலிருந்து எதையும் pkg கொண்டு நிறுவலாம்:

pkg search postgres
pkg install postgresql

கூடுதல் விசை வரிசையில் ☰-ஐத் தொட்டால் பக்கப் பட்டி: அமர்வுகள், விசைப்பலகை மாற்றி, VS Code, Desktop. இடது ஓரத்திலிருந்து உள்ளே இழுத்தாலும் திறக்கும் — சைகை வழிசெலுத்தல் உள்ள கைபேசிகளைத் தவிர; அவற்றில் அந்த இழுப்பு பின்செல்லும். Desktop, VS Code குறுக்குவழிகளுக்கு முகப்புத் திரையில் qos சின்னத்தை நீண்ட நேரம் அழுத்துங்கள்.

உங்கள் கோப்புகள்

உங்கள் திட்டங்கள் qos-இன் வீட்டுக் கோப்புறையில் இருக்கும். கைபேசியின் பகிர்ந்த சேமிப்பை (Downloads, Pictures, கேமரா காட்சிகள்) அணுக, ஒருமுறை இயக்குங்கள்:

termux-setup-storage

அது அனுமதி கேட்டு, அந்தக் கோப்புறைகளுக்கான இணைப்புகளுடன் ~/storage-ஐ உருவாக்கும்.

VS Code

பக்கப் பட்டியில் (☰ விசை) VS Code-ஐத் தொடுங்கள், அல்லது qos சின்னத்தை நீண்ட நேரம் அழுத்தி VS Code-ஐத் தேர்ந்தெடுங்கள். code-server இயங்கவில்லை என்றால் qos அதைப் பின்னணியில் தொடங்கி, ~/.config/code-server/config.yaml-இல் உள்ள கடவுச்சொல்லைக் கொண்டு உங்களை உள்நுழைக்கும்.

கடவுச்சொல் வேண்டுமென்றே இயக்கத்தில் உள்ளது: கைபேசியில் உள்ள எந்தச் செயலியும் 127.0.0.1:8080-ஐ அணுக முடியும், code-server கட்டளைகளை இயக்க முடியும். நீங்களே தொடங்க: code-server.

qos Desktop

qos F-Droid களஞ்சியத்திலிருந்து qos Desktop-ஐ நிறுவி, அதைத் திறந்து Start the desktop-ஐத் தொடுங்கள்; அல்லது qos பக்கப் பட்டியில் (☰ விசை) Desktop-ஐத் தொடுங்கள். முதல் முறை qos, XFCE-ஐயும் (சுமார் 100 MB) qos-x11 தொகுப்பையும் நிறுவி, மேசைத்தளத்தைத் திறக்கும். முனையத்திலிருந்து: qos-desktop.

நிறுத்த: XFCE-இலிருந்து வெளியேறுங்கள், அல்லது qos Desktop அறிவிப்பில் Exit, அல்லது தொடங்கிய அமர்வில் Ctrl+C. முனையத்திலிருந்து தொடங்கும் வரைகலை நிரல்களுக்கு DISPLAY=:1 தேவை.

திரை கருப்பாகவே இருந்தால் அல்லது நிறங்கள் மாறித் தெரிந்தால், ஒரு விருப்பத்துடன் கைமுறையாகத் தொடங்குங்கள்:

termux-x11 :1 -legacy-drawing -xstartup "xfce4-session"
termux-x11 :1 -force-bgra -xstartup "xfce4-session"

இ-தமிழ்

இ-தமிழ் நிரலை மெய்நிகர் இயந்திரத்தில் இயக்கவும், இயக்காமலேயே சரிபார்க்கவும்:

etamil --vm program.qmz
etamil --check program.qmz

நிலையான நூலகம் $ETAMIL_PATH-இல் உள்ளது; எனவே இறக்கு "nUlakam/…" எந்தக் கோப்புறையிலிருந்தும் இயங்கும். மொழியை etamil.in-இல் கற்றுக்கொள்ளுங்கள்.

பணி நிற்காமல் இருக்க

ஆண்ட்ராய்டு 12 மற்றும் புதியவை பின்னணியில் நீண்ட நேரம் இயங்கும் கட்டுமானங்கள், VS Code, மேசைத்தளம் போன்றவற்றை நிறுத்தக்கூடும். ஆண்ட்ராய்டு 14 மற்றும் புதியவற்றில் Developer options-ஐ இயக்கி Disable child process restrictions-ஐச் செயல்படுத்துங்கள். qos-இன் மின்கலப் பயன்பாட்டை Unrestricted என அமைப்பதும் உதவும்.

புதுப்பிப்புகள்

F-Droid களஞ்சியத்துடன், qos-உம் qos Desktop-உம் மற்ற செயலிகளைப் போலவே புதுப்பிக்கப்படும். qos-க்குள் உள்ள தொகுப்புகளைப் புதுப்பிக்க:

pkg upgrade

சிக்கல் தீர்வு

அமைப்பு பிழையுடன் நின்றது

இணைய இணைப்பைச் சரிபார்த்து qos-setup-ஐ மீண்டும் இயக்குங்கள். ஒவ்வொரு படியையும் மீண்டும் இயக்கலாம்.

"qos Desktop is not installed"

qos F-Droid களஞ்சியத்திலிருந்தோ qos-desktop GitHub வெளியீட்டிலிருந்தோ qos Desktop-ஐ நிறுவி, மீண்டும் Desktop-ஐத் தொடுங்கள்.

"Signature verification … failed"

qos Desktop-உம் qos-x11 தொகுப்பும் வெவ்வேறு மூலங்களிலிருந்து வந்துள்ளன. இரண்டையும் Termux-இலிருந்து அல்ல, qos வெளியீடுகளிலிருந்தே நிறுவுங்கள்.

VS Code திறக்கவில்லை

பிழையைப் பார்க்க முனையத்தில் code-server இயக்குங்கள். அது நிறுவப்படவில்லை என்றால் qos-setup இயக்குங்கள்.

கேள்விகள்

qos இலவசமா?

ஆம். qos, GNU GPL v3 உரிமத்தின் கீழ் உள்ள கட்டற்ற மென்பொருள்; விளம்பரங்களோ, செயலிக்குள் வாங்குதல்களோ, கணக்கோ இல்லை.

qos-க்கு ரூட் தேவையா?

இல்லை. எல்லாமே செயலியின் சொந்தச் சேமிப்பிடத்துக்குள், சாதாரண செயலி அனுமதிகளுடன் இயங்குகின்றன.

qos, Termux-இலிருந்து எப்படி வேறுபடுகிறது?

qos, Termux-ஐ அடிப்படையாகக் கொண்டு அதன் தொகுப்புத் திரட்டைத் தக்க வைத்துக்கொள்கிறது. அதனுடன் முழுக் கருவித்தொகுப்பின் ஒருமுறை அமைப்பு, செயலிக்குள்ளேயே VS Code, qos Desktop, இ-தமிழ் ஆகியவற்றைச் சேர்க்கிறது — எந்த அமைப்பும் இல்லாமலேயே புதிய கைபேசி நிரலாக்கக் கணினியாகிறது.

Termux-ஐயும் வைத்திருக்கலாமா?

முடியாது. எல்லா Termux தொகுப்புகளும் இயங்குவதற்காக qos, Termux-இன் தொகுப்புப் பெயரையே பயன்படுத்துகிறது; அந்தப் பெயரில் ஒரு செயலியை மட்டுமே ஆண்ட்ராய்டு அனுமதிக்கும்.

qos ஏன் Google Play-இல் இல்லை?

செயலிகள் சமீபத்திய ஆண்ட்ராய்டு பதிப்புகளை இலக்காகக் கொள்ள வேண்டும் என்று Play கோருகிறது; அவை பதிவிறக்கிய நிரல்களை ஒரு செயலி இயக்க அனுமதிப்பதில்லை. நிரலாக்கக் கணினி செய்ய வேண்டியதே அதுதான்.

qos ஆண்ட்ராய்டு கைபேசியையோ டேப்லெட்டையோ நிரலாக்கக் கணினியாக மாற்றுகிறது. GNU GPL v3 உரிமத்தின் கீழ் கட்டற்ற மென்பொருள்.
