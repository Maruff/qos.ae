Get qos

qos is free. Choose how to install it; F-Droid is recommended because updates then arrive by themselves.

Recommended

F-Droid repository

Add the qos repository to an F-Droid client once.

  • Automatic updates for qos and qos Desktop
  • Signed index, checked against a fingerprint
  • Needs an F-Droid client
  1. Install an F-Droid client: F-Droid, Droid-ify or Neo Store.
  2. On your phone, tap Add the qos repository, or add it by hand: https://qos.ae/fdroid/repoand check this fingerprint:6A57FBAEAE589E8B7D1BC7F2758A9E747A6CF66A22603A1718E16F390E944AB8
  3. Search for qos and install it. Add qos Desktop too if you want the desktop.
Direct

GitHub releases

Download the APK and install it yourself.

  • No extra app
  • SHA-256 checksums with every release
  • Update by hand
  1. Open the latest qos release.
  2. Download the APK for your phone (see below).
  3. Open it, and allow your browser to install apps when Android asks.
Updater

Obtainium

Let Obtainium follow the GitHub releases.

  • Updates from GitHub, without F-Droid
  • One more app to set up
  1. Install Obtainium.
  2. Add https://github.com/Maruff/qos as an app source.

Which APK

Pick the APK for your processor

F-Droid picks for you. From GitHub, choose by your phone's processor; if you are not sure, it is almost certainly arm64-v8a.

Add-on

qos Desktop

Want windows and a mouse pointer? Install qos Desktop after qos: from the same F-Droid repository, or qos-desktop.apk from GitHub. Then tap Desktop in the qos side drawer.

qos Desktop only works with qos from these same sources, because both must be signed with the qos key.

Verify

Check what you install

Every release lists SHA-256 checksums in sha256sums.txt. These are the certificates that sign qos:

qos and qos Desktop APKs379DA39A198B76D7AE4733C8FC78648CB509D2C1174D03E64442C9337FDEF8DA
qos F-Droid repository6A57FBAEAE589E8B7D1BC7F2758A9E747A6CF66A22603A1718E16F390E944AB8

With the Android SDK: apksigner verify --print-certs qos-….apk shows the APK's SHA-256 certificate digest.

Requirements

What your device needs

MinimumRecommended
Android7.0 (Nougat)10 or newer
ProcessorARM (32 or 64-bit) or x8664-bit ARM (arm64-v8a), which almost every phone since 2017 has. The eTamil toolchain needs it.
Memory (RAM)3 GB4 GB or more for VS Code, Rust builds and qos Desktop; 6 to 8 GB for local AI models
Free storage4 GB8 GB or more. The developer toolset takes about 2.3 GB once installed, and qos Desktop's XFCE about 0.6 GB more.
InternetFor the first launch: about 500 MBWi-Fi for setup. After that, qos works offline.
InputThe on-screen keyboardA Bluetooth or USB keyboard, especially on a tablet; a mouse for qos Desktop

Storage and download sizes are measured from the current package versions and change as they update. Memory figures are guidance, not hard limits.

qos replaces Termux. It uses Termux's package name so that every Termux package works, so the two cannot be installed side by side, and Termux add-ons will not work with qos. Back up anything you need from Termux first.
Not on Google Play. Play does not allow apps that run programs they download, which is what a development machine does.

qos turns an Android phone or tablet into a development machine. Free software under the GNU GPL v3.
