Roadmap

Where qos is, and where it is going

qos ships small releases every month. Anything not yet released can change, and what you say in the forum shapes the order.

Available now · v0.2

A working development machine

  • Linux terminal with the full Termux package collection
  • One-time setup of git, clang, make, Python, Rust and Java 17
  • VS Code inside the app, signed in automatically
  • qos Desktop: an XFCE desktop for graphical apps New
  • eTamil compiler and its library, nUlakam (64-bit ARM)
  • Signed releases on GitHub and the qos F-Droid repository
Next

Smoother everyday use

  • eTamil built natively for Android, so eTamil programs can reach websites and APIs by name
  • Choose which tools to install at first launch
  • The app's own screens in Tamil
  • VS Code settings: start on launch, choose the port
Planned

Kits for every kind of work

  • Setup by purpose: choose what you are here to do at first launch, and qos installs the matching kit
  • Kits for Android apps, games, animation, film, IoT, security and local AI
  • qos add-ons for the device: notifications, sensors, camera, widgets and start-on-boot scripts
  • A full Debian environment for tools Termux does not package
Exploring

Ideas we are looking into

  • qos Desktop built into qos itself: one app instead of two
  • Flashing boards over USB without root, and eTamil on Arduino from the phone
  • Ready-made lessons for classrooms
  • Documentation in Tamil and English

Planned

Release notes

What changed

11 October 2026

qos 0.2 and qos Desktop 0.1

  • A Desktop button in the drawer opens an XFCE desktop on qos Desktop, setting it up the first time.
  • qos Desktop: the Termux:X11 display, signed with the qos key so it runs as part of qos.
  • Both are in the qos F-Droid repository.

qos 0.2.0 · qos Desktop 0.1.0

10 October 2026

qos 0.1

  • The first release: Termux with a one-time setup of git, clang, Python, Rust, Java 17, code-server and eTamil.
  • VS Code inside the app, with automatic sign-in.
  • Signed APKs for four processor types, and the qos F-Droid repository.
