English

உங்கள் கைபேசியில் ஒரு நிரலாக்கக் கணினி

qos உங்கள் ஆண்ட்ராய்டு கைபேசியையோ டேப்லெட்டையோ உண்மையான மென்பொருளை எழுதி, கட்டி, இயக்கும் இடமாக மாற்றுகிறது: லினக்ஸ் முனையம், VS Code, தொகுப்பிகள், இ-தமிழ் கருவிகள் — எல்லாம் ஒரே செயலியில்.

qos-ஐ நிறுவுங்கள் திட்டப் பாதையைப் பாருங்கள்
இலவசம், திறந்த மூலம் (GPLv3) கணக்கு இல்லை, விளம்பரம் இல்லை, கண்காணிப்பு இல்லை அமைத்த பின் இணையம் இல்லாமலும் இயங்கும் ரூட் தேவையில்லை

யாருக்காக

கைபேசியும், கட்ட ஒரு யோசனையும் உள்ள எவருக்கும்

நிரலாக்கம் கற்க விரும்பும் பெரும்பாலானோரிடம் ஏற்கனவே ஓர் ஆண்ட்ராய்டு கைபேசி இருக்கிறது; மடிக்கணினி இருப்பவர்கள் மிகக் குறைவு. qos அவர்களுக்காக — தங்கள் கருவிகள் எப்போதும் கையருகே இருக்க வேண்டும் என்று விரும்பும் எவருக்காகவும்.

மாணவர்கள்

கணினி ஆய்வகத்துக்குக் காத்திருக்காமல், கையில் உள்ள கைபேசியிலேயே Python, C, Java, Rust கற்கலாம்.

நிரலாக்கம் கற்கும் தமிழர்கள்

இ-தமிழில் தமிழிலேயே நிரல் எழுதுங்கள்; அதே முனையத்திலிருந்து பிற மொழிகளுக்கும் செல்லுங்கள்.

ஆசிரியர்களும் கல்லூரிகளும்

கைபேசிகளிலும் டேப்லெட்டுகளிலும் நிரலாக்க வகுப்புகளை நடத்துங்கள். ஒவ்வொரு மாணவருக்கும் ஒரே கருவிகள், ஒரே அமைப்பு.

பணிபுரியும் நிரலாளர்கள்

மேசையை விட்டு விலகியிருக்கும்போதும் பிழை திருத்தலாம், கிளையைச் சரிபார்க்கலாம், commit அனுப்பலாம், SSH வழியே சேவையகத்தை அணுகலாம்.

இ-தமிழ் நிரலாளர்கள்

உண்மையான தொகுப்பியைக் கொண்டு இ-தமிழ் நிரல்கள், கூறுகள், சேவையகங்களை ஆண்ட்ராய்டிலேயே கட்டிச் சோதிக்கலாம்.

ஆர்வலர்கள்

ஷெல் நிரல்களால் கைபேசிப் பணிகளைத் தானியக்கமாக்குங்கள், சிறு சேவையகங்களை இயக்குங்கள், லினக்ஸை ஒரே செயலிக்குள் பாதுகாப்பாக ஆராயுங்கள்.

என்ன செய்யலாம்

உண்மையான கருவிகள், விளையாட்டுப் பொருள் அல்ல

லினக்ஸில் நிரலாளர்கள் பயன்படுத்தும் அதே தொகுப்பிகளும் கருவிகளும் qos-இல் இயங்குகின்றன. இங்கே நீங்கள் கட்டுவது உண்மையான மென்பொருள்.

பல மொழிகளில் நிரல் எழுதுங்கள்

Python, C, C++ (clang), Rust, Java 17, JavaScript (Node.js), இ-தமிழ் — முதல் முறை திறக்கும்போதே நிறுவப்படுகின்றன.

VS Code-இல் திருத்துங்கள்

முழுமையான VS Code (code-server) கைபேசியிலேயே இயங்குகிறது; பக்கப் பட்டியிலிருந்து திறக்கலாம். Open VSX-இலிருந்து நீட்சிகளும் கிடைக்கும்.

git உடன் பணியாற்றுங்கள்

முனையத்திலிருந்தோ VS Code-இலிருந்தோ GitHub, GitLab அல்லது எந்த git சேவையகத்துடனும் clone, branch, commit, push செய்யலாம்.

சேவையகங்களையும் API-களையும் இயக்குங்கள்

கைபேசியில் ஒரு வலைச் சேவையகத்தையோ இ-தமிழ் API-யையோ தொடங்கி, உலாவியில் அல்லது உங்கள் வலையமைப்பில் உள்ள மற்றொரு சாதனத்தில் திறக்கலாம்.

ஆயிரக்கணக்கான தொகுப்புகள்

Termux களஞ்சியங்களில் உள்ள அனைத்தும் ஒரு pkg install தொலைவில்: தரவுத்தளங்கள், திருத்திகள், கட்டுமானக் கருவிகள், SSH மற்றும் பல.

உங்கள் படைப்பு உங்கள் சாதனத்திலேயே

மேகக்கணினி இல்லை, உள்நுழைவு இல்லை. நீங்கள் அனுப்பும் வரை உங்கள் நிரல் உங்கள் கைபேசியிலேயே இருக்கும்.

தேவைகள்

உங்கள் சாதனத்துக்கு என்ன வேண்டும்

கடந்த சில ஆண்டுகளில் வந்த பெரும்பாலான ஆண்ட்ராய்டு கைபேசிகளிலும் டேப்லெட்டுகளிலும் qos இயங்கும். விசைப்பலகையுடன் கூடிய புதிய கைபேசி மிக வசதியானது.

குறைந்தபட்சம்பரிந்துரைக்கப்படுவது
ஆண்ட்ராய்டு7.0 (Nougat)10 அல்லது அதற்குப் புதியது
செயலகம்ARM (32 அல்லது 64-பிட்) அல்லது x8664-பிட் ARM (arm64-v8a) — 2017 முதல் வந்த ஏறக்குறைய எல்லாக் கைபேசிகளிலும் உள்ளது. இ-தமிழ் கருவிகளுக்கு இது தேவை.
நினைவகம் (RAM)3 GB4 GB அல்லது அதற்கு மேல் — VS Code, Rust கட்டுமானங்களுக்கு
காலி இடம்4 GBஉங்கள் திட்டங்களுக்காக 8 GB அல்லது அதற்கு மேல். முழுக் கருவித் தொகுப்பும் நிறுவிய பின் சுமார் 2.3 GB எடுக்கும்.
இணையம்முதல் முறை திறக்க: சுமார் 500 MBஅமைப்புக்கு Wi-Fi. அதன் பின் qos இணையம் இல்லாமலும் இயங்கும்.
உள்ளீடுதிரை விசைப்பலகைBluetooth அல்லது USB விசைப்பலகை — குறிப்பாக டேப்லெட்டில்

சேமிப்பு, பதிவிறக்க அளவுகள் தற்போதைய தொகுப்புப் பதிப்புகளிலிருந்து அளக்கப்பட்டவை; அவை புதுப்பிக்கப்படும்போது மாறும். நினைவக அளவுகள் வழிகாட்டுதல் மட்டுமே, கட்டாய வரம்புகள் அல்ல.

நிறுவுதல்

qos-ஐப் பெறுங்கள்

qos Google Play-இல் இல்லை: பதிவிறக்கிய நிரல்களை இயக்கும் செயலிகளை Play அனுமதிப்பதில்லை, ஒரு நிரலாக்கக் கணினி செய்ய வேண்டியது அதுதான். அதற்குப் பதிலாக இவற்றில் ஒன்றைத் தேர்ந்தெடுங்கள்.

F-Droid (பரிந்துரை)

புதுப்பிப்புகள் தாமாகவே வரும்.

  1. ஒரு F-Droid செயலியை நிறுவுங்கள்: F-Droid, Droid-ify அல்லது Neo Store.
  2. உங்கள் கைபேசியில் qos களஞ்சியத்தைச் சேர் என்பதைத் தொடுங்கள், அல்லது கைமுறையாகச் சேருங்கள்: https://qos.ae/fdroid/repo இந்தக் கைரேகையைச் சரிபாருங்கள்: 6A57FBAEAE589E8B7D1BC7F2758A9E747A6CF66A22603A1718E16F390E944AB8
  3. qos எனத் தேடி நிறுவுங்கள்.

GitHub-இலிருந்து பதிவிறக்கம்

APK-ஐ நேரடியாக நிறுவுங்கள்.

  1. சமீபத்திய வெளியீட்டைத் திறங்கள்.
  2. உங்கள் கைபேசிக்கான APK-ஐப் பதிவிறக்குங்கள். பெரும்பாலான கைபேசிகளுக்கு arm64-v8a.
  3. அதைத் திறந்து, ஆண்ட்ராய்டு கேட்கும்போது உலாவிக்குச் செயலிகளை நிறுவ அனுமதி கொடுங்கள்.

ஒவ்வொரு வெளியீட்டிலும் SHA-256 சரிபார்ப்புத் தொகைகள் உள்ளன. Obtainium வெளியீடுகளைப் பின்தொடர்ந்து qos-ஐப் புதுப்பிக்கும்.

முதல் முறை திறக்கும்போது

முதல் முறை திறக்கும்போது qos தன் கருவிகளை அமைக்கிறது.

  1. Wi-Fi-இல் இணைந்து திரையை அணையாமல் வைத்திருங்கள்: அமைப்பு சுமார் 500 MB பதிவிறக்கும்.
  2. முனையத்தில் Done வரும் வரை காத்திருங்கள்; சில நிமிடங்கள் ஆகும்.
  3. இடது ஓரத்திலிருந்து உள்ளே இழுத்து VS Code-ஐத் தொடுங்கள், அல்லது தட்டச்சு செய்யத் தொடங்குங்கள்.

அமைப்பு இடையில் நின்றால், அடுத்த முறை தொடரும்; அல்லது qos-setup இயக்குங்கள்.

qos, Termux-க்குப் பதிலாக நிறுவப்படும். எல்லா Termux தொகுப்புகளும் இயங்குவதற்காக அது Termux-இன் தொகுப்புப் பெயரையே பயன்படுத்துகிறது. எனவே இரண்டையும் ஒரே நேரத்தில் நிறுவ முடியாது; F-Droid-இல் உள்ள Termux இணைப்புச் செயலிகளும் qos உடன் இயங்காது.
ஆண்ட்ராய்டு 12 மற்றும் புதியவை பின்னணியில் நீண்ட நேரம் இயங்கும் கட்டுமானங்களையோ VS Code-ஐயோ நிறுத்தக்கூடும். ஆண்ட்ராய்டு 14-இல் Developer options-ஐ இயக்கி "Disable child process restrictions" என்பதைச் செயல்படுத்துங்கள்.

திட்டப் பாதை

qos இப்போது எங்கே, எங்கே செல்கிறது

qos ஒவ்வொரு மாதமும் சிறு வெளியீடுகளை வெளியிடுகிறது. இது இன்றைய திட்டம்; இன்னும் வெளியிடப்படாதவை மாறக்கூடும். கலந்துரையாடல் மன்றத்தில் நீங்கள் சொல்லும் கருத்துகள் வரிசையைத் தீர்மானிக்கின்றன.

qos இலவசமா?

ஆம். qos, GNU GPL v3 உரிமத்தின் கீழ் உள்ள கட்டற்ற மென்பொருள். விளம்பரங்கள் இல்லை, செயலிக்குள் வாங்குதல்கள் இல்லை, கணக்கும் தேவையில்லை.

qos-க்கு ரூட் தேவையா?

இல்லை. எல்லாமே செயலியின் சொந்தச் சேமிப்பிடத்துக்குள், சாதாரண செயலி அனுமதிகளுடன் இயங்குகின்றன.

qos, Termux-இலிருந்து எப்படி வேறுபடுகிறது?

qos, Termux-ஐ அடிப்படையாகக் கொண்டு அதன் தொகுப்புத் திரட்டைத் தக்க வைத்துக்கொள்கிறது. அதனுடன் முழுமையான கருவித் தொகுப்பின் ஒருமுறை அமைப்பு, செயலிக்குள்ளேயே VS Code, இ-தமிழ் கருவிகள் ஆகியவற்றைச் சேர்க்கிறது — எந்த அமைப்பும் செய்யாமலேயே புதிய கைபேசி நிரலாக்கக் கணினியாகிறது.

Termux-ஐயும் வைத்திருக்கலாமா?

முடியாது. எல்லா Termux தொகுப்புகளும் இயங்குவதற்காக qos, Termux-இன் தொகுப்புப் பெயரையே பயன்படுத்துகிறது; அந்தப் பெயரில் ஒரு செயலியை மட்டுமே ஆண்ட்ராய்டு அனுமதிக்கும். qos-ஐ நிறுவும் முன் Termux-இல் தேவையானவற்றைக் காப்புப்பிரதி எடுத்துக்கொள்ளுங்கள்.

qos ஏன் Google Play-இல் இல்லை?

செயலிகள் சமீபத்திய ஆண்ட்ராய்டு பதிப்புகளை இலக்காகக் கொள்ள வேண்டும் என்று Google Play கோருகிறது; அந்தப் பதிப்புகள் பதிவிறக்கிய நிரல்களை ஒரு செயலி இயக்க அனுமதிப்பதில்லை. நிரலாக்கக் கணினி செய்ய வேண்டியதே அதுதான். எனவே qos, F-Droid, GitHub வழியாக வழங்கப்படுகிறது.

qos அல்லது இந்த இணையதளம் தரவு சேகரிக்கிறதா?

இல்லை. qos-இல் பகுப்பாய்வோ தொலைஅளவீடோ இல்லை; இந்த இணையதளத்தில் குக்கீகளும் கண்காணிப்பும் இல்லை.
