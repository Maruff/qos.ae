Turn an Android phone or tablet into a development machine.

Install qos Source code

What you get

A real Linux terminal

Built on Termux, with thousands of packages a pkg install away.

VS Code, inside the app

code-server runs on the device and opens from the side drawer. No account, no cloud.

Compilers and runtimes

git, clang, make, Python, Rust, Java 17 and Node.js, set up on first launch.

eTamil

The eTamil compiler and its standard library, nUlakam, ready on the command line.

Install

With F-Droid recommended: updates arrive by themselves

  1. Install an F-Droid client: F-Droid, Droid-ify or Neo Store.
  2. Add the qos repository. On your phone, tap Add the qos repository, or add it by hand: https://qos.ae/fdroid/repo Check that the client shows this fingerprint: 6A57FBAEAE589E8B7D1BC7F2758A9E747A6CF66A22603A1718E16F390E944AB8
  3. Search for qos and install it.

From GitHub

Download the APK for your phone from the latest release. Most phones need arm64-v8a. Each release lists SHA-256 checksums. Obtainium can follow the releases for you.

First launch

qos sets up its tools the first time it opens. That downloads several hundred megabytes, so use Wi-Fi and keep the screen on. If it is interrupted, it carries on next time, or run qos-setup.

Before you install

qos replaces Termux. It uses Termux's package name so that every Termux package works, which means the two cannot be installed side by side. Termux add-ons from F-Droid will not work with qos.

Android 7.0 or newer. On Android 12 and later, Android may stop long-running work such as builds or code-server. On Android 14 you can turn this off in Developer options with "Disable child process restrictions".

Not on Google Play. Google Play does not allow apps that run programs they download, which is what a development machine does.
