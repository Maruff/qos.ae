A development machine in your pocket

qos turns an Android phone or tablet into a place to write, build and run real software: a Linux terminal, VS Code, compilers and the eTamil toolchain, in one app.

Who it's for

For anyone with a phone and something to build

Most people who want to learn programming already own an Android phone. Far fewer own a laptop. qos is for them, and for anyone who wants their tools within reach.

Students

Learn Python, C, Java or Rust on the device you already carry, without waiting for a computer lab.

Tamil speakers learning to code

Write programs in Tamil with eTamil, and move on to other languages from the same terminal.

Teachers and colleges

Run programming classes on phones and tablets. Every student gets the same tools, set up the same way.

Working developers

Fix a bug, review a branch, push a commit or reach a server over SSH, away from your desk.

eTamil developers

Build and test eTamil programs, modules and servers on Android, with the real compiler.

Tinkerers

Automate your phone with shell scripts, run small servers and explore Linux, safely, inside one app.

What you can do

Real tools, not a toy

qos runs the same compilers and tools developers use on Linux. What you build here is real software.

Write code in many languages

Python, C and C++ (clang), Rust, Java 17, JavaScript (Node.js) and eTamil are installed at first launch.

Edit in VS Code

A full VS Code (code-server) runs on the device and opens from the side drawer, with extensions from Open VSX.

Work with git

Clone, branch, commit and push to GitHub, GitLab or any git server, from the terminal or from VS Code.

Run servers and APIs

Start a web server or an eTamil API on the phone and open it in the browser, or from another device on your network.

Install thousands of packages

Everything in the Termux repositories is a pkg install away: databases, editors, build tools, SSH and more.

Keep your work on your device

No cloud and no sign-in. Your code stays on your phone until you push it somewhere.

Requirements

What your device needs

qos runs on most Android phones and tablets from the last several years. A recent phone with a keyboard is the most comfortable.

Storage and download sizes are measured from the current package versions and will change as they update. Memory figures are guidance, not hard limits.

Install

Get qos

qos is not on Google Play, because Play does not allow apps that run programs they download, which is what a development machine does. Choose one of these instead.

F-Droid (recommended)

Updates arrive by themselves.

  1. Install an F-Droid client: F-Droid, Droid-ify or Neo Store.
  2. On your phone, tap Add the qos repository, or add it by hand: https://qos.ae/fdroid/repo and check this fingerprint: 6A57FBAEAE589E8B7D1BC7F2758A9E747A6CF66A22603A1718E16F390E944AB8
  3. Search for qos and install it.

Download from GitHub

Install the APK directly.

  1. Open the latest release.
  2. Download the APK for your phone. Most phones need arm64-v8a.
  3. Open it and allow your browser to install apps when Android asks.

Each release lists SHA-256 checksums. Obtainium can follow releases and update qos for you.

First launch

qos sets up its tools the first time it opens.

  1. Connect to Wi-Fi and keep the screen on: setup downloads about 500 MB.
  2. Wait for Done in the terminal. It takes several minutes.
  3. Swipe in from the left edge and tap VS Code, or start typing.

If setup is interrupted, it carries on next time, or run qos-setup.

qos replaces Termux. It uses Termux's package name so that every Termux package works, so the two cannot be installed side by side, and Termux add-ons from F-Droid will not work with qos.
Android 12 and newer may stop long-running work such as builds or VS Code in the background. On Android 14, turn on Developer options and enable "Disable child process restrictions".

Beyond code

Apps, games, cartoons, films, IoT, security and AI

Can qos do more than run code? Mostly yes, with honest limits. Here is what works today and what the roadmap adds.

Mobile apps

Today

Build Android apps from the terminal: Java 21, Kotlin, Gradle, aapt2, d8, apksigner and adb are all in the package collection. Web apps work fully.

Coming

An Android kit set up in one step, and a starter project that builds and installs on the same phone with one command.

Limits

Builds are slower than on a laptop. Flutter does not run on Android devices yet.

Games

Today

Web games in HTML5 and JavaScript, played in the browser, and text games in any language.

Coming

Godot 4, LÖVE, pygame and raylib, running on an X11 display inside qos.

Limits

2D and light 3D. Phones lack the desktop graphics drivers that heavy 3D games need.

Cartoons and animation

Today

Animated explainers with manim, and image work with ImageMagick and Python.

Coming

Frame-by-frame 2D animation in Krita, and drawing in Inkscape and GIMP, on the X11 display.

Limits

No Blender, so no 3D animation. Long renders are slow and warm the phone.

Films

Today

Edit with ffmpeg: trim, join, add music and Tamil subtitles, and export for YouTube or WhatsApp.

Coming

Timeline editing in Kdenlive or Shotcut, and sound in Audacity, on the X11 display.

Limits

Shoot with the phone's own camera app; qos edits the footage. Rendering 4K video is slow.

IoT

Today

MQTT with Mosquitto, Python and Node.js services, and talking to ESP32 or Arduino boards over Wi-Fi.

Coming

An IoT kit set up in one step: an MQTT broker, dashboards and over-the-air updates for ESP32 boards.

Limits

Flashing boards over USB without root is hard on Android. We are exploring it, together with eTamil on Arduino from the phone.

Cybersecurity

Today

Scan your own network with nmap, encrypt with GnuPG and age, manage SSH keys, run WireGuard and Tor, scan files with ClamAV and YARA, and take apart programs and Android apps with radare2, gdb, apktool and jadx.

Coming

A security kit set up in one step, with practice exercises for learning, and Wireshark on the X11 display.

Limits

Capturing network traffic and Wi-Fi monitoring need root. qos is for learning and defending your own systems; attack frameworks are not included.

AI

Today

Run open-weight language models on the phone with llama.cpp or Ollama, and machine learning with PyTorch, ONNX Runtime, NumPy and SciPy. No account and no paid AI service.

Coming

A local AI kit set up in one step: a chosen model downloaded and ready, and a code assistant in VS Code that runs on the device.

Limits

Small models only: about 1 to 4 billion parameters, needing roughly 4 to 8 GB of RAM. Answers are slower than cloud services.

Questions

Frequently asked

Is qos free?

Yes. qos is free software under the GNU GPL v3. There are no ads, no in-app purchases and no account.

Does qos need root?

No. Everything runs inside the app's own storage, with normal app permissions.

How is qos different from Termux?

qos is built on Termux and keeps its package collection. It adds a one-time setup of a complete toolset, VS Code inside the app, and the eTamil toolchain, so a new phone becomes a development machine without any configuration.

Can I keep Termux installed?

No. qos uses Termux's package name so that every Termux package works with it, and Android allows only one app with that name. Back up anything you need from Termux before installing qos.

Why is qos not on Google Play?

Google Play requires apps to target recent Android versions, which do not allow an app to run programs it downloads. A development machine has to do exactly that, so qos is distributed through F-Droid and GitHub instead.

Does qos or this website collect data?

No. qos has no analytics and no telemetry, and this website uses no cookies and no tracking.
